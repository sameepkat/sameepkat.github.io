  • Lower level doesn't mean faster performance 2026-08-03

    We all assume that the lower the level, the faster the performance gets.

    Machine Code > Assembly > Compiled Languages > Interpreted Languages

    This however, is a common misconception. Lower level does not inherently mean faster.

    An optimized higher level is going to be better than lower level unoptimized code.

    Optimized Higher Level > Unoptimized Lower Level

    A algorithm with run time of O(n^3) in assembly is going to be slower than an algorithm with run time of O(n) in some higher level languages.

  • Tokenization 2026-07-23

    We know, computers work with numbers and numbers only. So, whenever we represent some other formats like Emojis or Strings, it is naturally represented using numbers inside the computer system.

    The same goes for LLMs. They can't just work on raw text. They are first converted to numbers before they can be processed. The tool that does this exactly is known as a tokenizer. It is quite similar in concept but different than tokenizer used by compilers.
